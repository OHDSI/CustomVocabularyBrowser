# Font sources

- Montserrat variable font: Google Fonts, `ofl/montserrat/Montserrat[wght].ttf`.
  Retrieved November 3, 2026 from https://github.com/google/fonts/tree/main/ofl/montserrat.
  Copyright 2024 The Montserrat.Git Project Authors.
  Distributed under SIL Open Font License 1.1; see `Montserrat-OFL.txt`.
- Helvetica Neue is not bundled or downloaded. CSS uses it only if available on
  the user's system, falling back to Helvetica and Arial. Availability and exact
  glyph appearance consequently depend on the operating system.
- Previously bundled Roboto Condensed remains with its original `OFL.txt` notice,
  but is not used by the Athena-inspired theme.
